About the GPDS Team

The Global Phishing Drill Service (GPDS) is the team responsible for running phishing simulations, awareness training, and human-risk reporting across every member firm. We standardize the methodology, run the campaigns, and centralize the results so leadership and local firms are working from the same numbers.

  • ✓One team running drills consistently across the network
  • ✓Open about methodology, data handling, and results
  • ✓Focused on reducing risk, not assigning blame

What the program covers

Global Simulations

Scheduled, no-warning phishing campaigns run consistently across every participating member firm, using the same methodology and scoring.

Unified Reporting

Results roll up into a single dashboard, tracking sent, opened, credential-submitted, and reported, and are exportable for audits and leadership reviews.

Targeted Remediation

Departments and individuals who need follow-up training are identified automatically, so remediation effort goes where it's actually needed.

How this works across firms

Historically, phishing awareness was run separately by each member firm, on different schedules and without shared visibility. GPDS standardizes the methodology and centralizes reporting, so global leadership and each local firm see the same numbers, measured the same way.

  • ✓One methodology across all firms
  • ✓Centralized, exportable reporting
  • ✓Faster identification of high-risk groups
  • ✓Shared benchmarks across the network
