Drill Types

GPDS rotates through four drill types, one per quarter, so every firm gets tested against a different attack pattern throughout the year. The current quarter is running a Clickbait drill.

Current Quarter
Clickbait
Enticing subject lines and fake offers designed to prompt an impulsive click.
Credential Harvesting
Fake login pages designed to capture usernames and passwords.
Malicious Attachment
Emails carrying attachments designed to look like legitimate documents.
Privileged Access User
Targeted attempts aimed at users with elevated system or admin access.
